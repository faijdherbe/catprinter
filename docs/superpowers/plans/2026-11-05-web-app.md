# Catprinter Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static PWA in `web/` that composes text and image sections, shows a 1-bit preview and prints it on the MX10 printer with Web Bluetooth. GitHub Pages publishes it.

**Architecture:** Three ES modules. `printer.js` makes packets and talks to the printer. `render.js` changes sections into a 1-bit bitmap of 384 px wide. `app.js` owns the DOM, the storage and the screens. `printer.js` and `render.js` do not touch the page DOM, so `test.html` tests them in headless Chrome.

**Tech Stack:** Plain HTML/JS (ES modules), Beer CSS 5.0.3, material-dynamic-colors 1.1.4, Material Symbols Outlined, marked 18.1.1, Web Bluetooth, Service Worker, GitHub Actions for Pages.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-05-web-app-design.md`. Rules: `CLAUDE.md`.
- No build step. No npm. Pinned local copies in `web/lib/`. Load nothing from a CDN at run time.
- Theme: `ui("theme", "#7540bf")`, mode `auto`.
- Printer: width 384 px. Defaults energy 12000, speed 32, feed 150 rows.
- All user text in ASD-STE100. Exact error texts are in the spec, section Errors.
- Chrome blocks ES modules on `file://`. Run the app locally with `python3 -m http.server 8000 -d web`, then open `http://localhost:8000/`.
- Public URL: `https://faijdherbe.github.io/catprinter/`.
- Tests: `sh web/run-tests.sh` prints `ok`, or `FAIL` and the failed checks.
- Each commit message ends with the two attribution lines from the session.

```js
// MX10 printer: packets (pure functions) and the Web Bluetooth transport.
// Protocol: see README.md -> Protocol notes.
export const WIDTH = 384;
export const SERVICE = 0xae30; // checked on the real printer in Task 1
const TX = 0xae01;
const RX = 0xae02;

export function crc8(data) {
  let c = 0;
  for (const x of data) {
    c ^= x;
    for (let i = 0; i < 8; i++) c = c & 0x80 ? ((c << 1) ^ 7) & 0xff : (c << 1) & 0xff;
  }
  return c;
}

export function pkt(cmd, payload) {
  const p = [...payload];
  return Uint8Array.from([0x51, 0x78, cmd, 0, p.length & 0xff, p.length >> 8, ...p, crc8(p), 0xff]);
}

// One 48-byte row per bitmap row. Bit 0 = leftmost pixel. 1 = black.
export function packRows(bitmap) {
  const rows = [];
  for (let y = 0; y < bitmap.height; y++) {
    const r = new Uint8Array(WIDTH / 8);
    for (let x = 0; x < WIDTH; x++) if (bitmap.data[y * WIDTH + x]) r[x >> 3] |= 1 << (x & 7);
    rows.push(r);
  }
  return rows;
}

export function printJob(bitmap, {energy, speed, feed}) {
  const blank = new Uint8Array(WIDTH / 8);
  return [
    pkt(0xA3, [0]), // get state
    pkt(0xA4, [0x33]), // quality
    pkt(0xA6, [0xAA, 0x55, 0x17, 0x38, 0x44, 0x5F, 0x5F, 0x5F, 0x44, 0x38, 0x2C]), // lattice start
    pkt(0xAF, [energy & 0xff, energy >> 8]),
    pkt(0xBD, [speed]),
    pkt(0xBE, [1]), // apply energy
    ...packRows(bitmap).map(r => pkt(0xA2, r)),
    ...Array.from({length: feed}, () => pkt(0xA2, blank)), // blank rows: 0xA1 feed does not always move the paper
    pkt(0xA6, [0xAA, 0x55, 0x17, 0, 0, 0, 0, 0, 0, 0, 0x17]), // lattice end
    pkt(0xA3, [0]),
  ];
}

const STATE_BITS = [[1, 'paper'], [2, 'cover'], [4, 'heat'], [8, 'battery']]; // 0x80 = busy, not an error
export const stateErrors = b => STATE_BITS.filter(([bit]) => b & bit).map(([, k]) => k);
```

```js
let device = null;
let tx = null;
let paused = false;
let resume = null;
let chunk = 512;
const sleep = ms => new Promise(r => setTimeout(r, ms));

export const supported = () => !!navigator.bluetooth;
export const isConnected = () => !!device?.gatt.connected;

export async function connect(onEvent) {
  if (!device) {
    device = await navigator.bluetooth.requestDevice({filters: [{namePrefix: 'MX'}], optionalServices: [SERVICE]});
    device.addEventListener('gattserverdisconnected', () => onEvent('disconnected'));
  }
  const service = await (await device.gatt.connect()).getPrimaryService(SERVICE);
  tx = await service.getCharacteristic(TX);
  const rx = await service.getCharacteristic(RX);
  rx.oncharacteristicvaluechanged = e => {
    const d = new Uint8Array(e.target.value.buffer);
    if (d.length < 7) return;
    if (d[2] === 0xAE) { // flow control: 0x10 = pause, 0x00 = resume
      paused = d[6] !== 0;
      if (!paused) resume?.();
    } else if (d[2] === 0xA3) onEvent('state', d[6]);
  };
  await rx.startNotifications();
  await write(pkt(0xA3, [0]));
  return device.name;
}

export function disconnect() {
  device?.gatt.disconnect();
}

// ponytail: if a large write fails (small BLE MTU), use 20-byte writes. The printer reads a byte stream.
async function write(p) {
  for (let i = 0; i < p.length; i += chunk) {
    try {
      await tx.writeValueWithoutResponse(p.slice(i, i + chunk));
    } catch (e) {
      if (chunk === 20) throw e;
      chunk = 20;
      return write(p.slice(i));
    }
  }
}

export async function print(bitmap, settings, onProgress) {
  const total = bitmap.height + settings.feed;
  let rows = 0;
  for (const p of printJob(bitmap, settings)) {
    if (paused) await new Promise(r => (resume = r));
    await write(p);
    if (p[2] === 0xA2 && ++rows % 8 === 0) {
      onProgress(rows, total);
      await sleep(20); // ponytail: fixed throttle, the same as catprint.py. If lines are missing, increase it.
    }
  }
  await sleep(1500); // the printer must empty its buffer before the next job
}
```

- [ ] **Step 3: Write `web/render.js` (text part)**

```js
// Sections -> 1-bit bitmap, 384 px wide. 1 = black. No page DOM is used.
import { Marked } from './lib/marked.esm.js';

export const WIDTH = 384;
const GAP = 8; // px between sections

// ->text<- on its own line = one centered line (not GFM).
const center = {
  name: 'center',
  level: 'block',
  start: src => src.match(/^->/m)?.index,
  tokenizer(src) {
    const m = /^->(.*?)<-[ \t]*(?:\n|$)/.exec(src);
    if (m) return {type: 'center', raw: m[0], tokens: this.lexer.inlineTokens(m[1].trim())};
  },
};
const md = new Marked({gfm: true, extensions: [center]});

export const pageSections = (template, content) =>
  template ? [...template.top, ...content, ...template.bottom] : content;

const measure = new OffscreenCanvas(1, 1).getContext('2d');
const fontOf = (s, size) => `${s.italic ? 'italic ' : ''}${s.bold ? 'bold ' : ''}${size}px ${s.mono ? 'monospace' : 'sans-serif'}`;
const unescape = t => t.replace(/&(amp|lt|gt|quot|#39);/g, (_, e) => ({amp: '&', lt: '<', gt: '>', quot: '"', '#39': "'"})[e]);

// Inline tokens -> runs [{text, bold, italic, mono}]
function runs(tokens, style = {}) {
  const out = [];
  for (const t of tokens ?? []) {
    if (t.type === 'strong') out.push(...runs(t.tokens, {...style, bold: true}));
    else if (t.type === 'em') out.push(...runs(t.tokens, {...style, italic: true}));
    else if (t.type === 'codespan') out.push({...style, mono: true, text: unescape(t.text)});
    else if (t.type === 'br') out.push({...style, text: '\n'});
    else if (t.type === 'checkbox') continue;
    else if (t.tokens) out.push(...runs(t.tokens, style));
    else out.push({...style, text: unescape(t.text ?? t.raw ?? '')});
  }
  return out;
}

// Layout makes a list of draw operations. raster() draws them on a canvas of the final height.
class Layout {
  ops = [];
  y = 0;

  // Wrap runs inside [x, x + w). Align each line.
  text(rs, x, w, size, align) {
    const lh = Math.round(size * 1.25);
    let line = [];
    let lineW = 0;
    const flush = () => {
      while (line.length && /^\s+$/.test(line.at(-1).text) && !line.at(-1).mono) lineW -= line.pop().w;
      let lx = x + (align === 'center' ? (w - lineW) / 2 : align === 'right' ? w - lineW : 0);
      for (const p of line) {
        this.ops.push({t: 'text', text: p.text, font: p.font, x: Math.round(lx), y: this.y + size});
        lx += p.w;
      }
      this.y += lh;
      line = [];
      lineW = 0;
    };
    for (const r of rs) {
      const font = fontOf(r, size);
      measure.font = font;
      for (const piece of r.text.split(/(\n|[ \t]+)/)) {
        if (!piece) continue;
        if (piece === '\n') { flush(); continue; }
        const pw = measure.measureText(piece).width;
        const space = /^\s+$/.test(piece);
        if (space && !line.length && !r.mono) continue;
        if (!space && line.length && lineW + pw > w) flush();
        line.push({text: piece, font, w: pw, mono: r.mono});
        lineW += pw;
      }
    }
    if (line.length) flush();
  }

  block(t, x, w, size, align) {
    switch (t.type) {
      case 'heading':
        this.text(runs(t.tokens, {bold: true}), x, w, Math.round(size * ([0, 1.6, 1.35, 1.15][t.depth] ?? 1)), align);
        break;
      case 'paragraph':
      case 'text':
        this.text(t.tokens ? runs(t.tokens) : [{text: unescape(t.text)}], x, w, size, align);
        break;
      case 'center':
        this.text(runs(t.tokens), x, w, size, 'center');
        break;
      case 'code':
        this.text([{mono: true, text: t.text}], x, w, Math.round(size * 0.85), 'left');
        break;
      case 'hr':
        this.ops.push({t: 'rect', x, y: this.y + Math.round(size / 2) - 1, w, h: 2});
        this.y += size;
        break;
      case 'blockquote': {
        const y0 = this.y;
        for (const c of t.tokens) this.block(c, x + 16, w - 16, size, align);
        this.ops.push({t: 'rect', x, y: y0, w: 4, h: this.y - y0});
        break;
      }
      case 'list': {
        const ind = Math.round(size * 1.5);
        t.items.forEach((it, i) => {
          const y0 = this.y;
          if (it.task) this.ops.push({t: 'box', x: x + 2, y: y0 + Math.round(size * 0.2), s: Math.round(size * 0.9), checked: it.checked});
          else this.ops.push({t: 'text', text: t.ordered ? `${(t.start || 1) + i}.` : '•', font: fontOf({}, size), x, y: y0 + size});
          for (const c of it.tokens) this.block(c, x + ind, w - ind, size, 'left');
        });
        break;
      }
      case 'table': {
        const n = t.header.length;
        const cw = Math.floor(w / n);
        const pad = 4;
        const y0 = this.y;
        const row = (cells, bold) => {
          const top = this.y;
          let bottom = top;
          cells.forEach((cell, i) => {
            this.y = top + pad;
            this.text(runs(cell.tokens, {bold}), x + i * cw + pad, cw - 2 * pad, size, t.align[i] || 'left');
            bottom = Math.max(bottom, this.y + pad);
          });
          this.y = bottom;
          this.ops.push({t: 'rect', x, y: bottom - 1, w: cw * n, h: 1});
        };
        this.ops.push({t: 'rect', x, y: y0, w: cw * n, h: 1});
        row(t.header, true);
        t.rows.forEach(r => row(r, false));
        for (let i = 0; i <= n; i++) this.ops.push({t: 'rect', x: Math.min(x + i * cw, x + cw * n - 1), y: y0, w: 1, h: this.y - y0});
        break;
      }
      case 'space':
      case 'checkbox':
        break;
      default:
        if (t.tokens) for (const c of t.tokens) this.block(c, x, w, size, align);
        else if (t.text) this.text([{text: t.text}], x, w, size, align);
    }
  }
}

function raster(ops, height) {
  const c = new OffscreenCanvas(WIDTH, height);
  const x = c.getContext('2d');
  x.fillStyle = '#fff';
  x.fillRect(0, 0, WIDTH, height);
  x.fillStyle = x.strokeStyle = '#000';
  x.lineWidth = 2;
  for (const o of ops) {
    if (o.t === 'text') {
      x.font = o.font;
      x.fillText(o.text, o.x, o.y);
    } else if (o.t === 'rect') x.fillRect(o.x, o.y, o.w, o.h);
    else if (o.t === 'box') {
      x.strokeRect(o.x + 1, o.y + 1, o.s - 2, o.s - 2);
      if (o.checked) {
        x.beginPath();
        x.moveTo(o.x + 4, o.y + o.s / 2);
        x.lineTo(o.x + o.s / 2.5, o.y + o.s - 4);
        x.lineTo(o.x + o.s - 4, o.y + 4);
        x.stroke();
      }
    }
  }
  return c;
}

function renderText(s) {
  const l = new Layout();
  const gap = Math.round(s.size * 0.4);
  for (const t of md.lexer(s.md)) {
    if (t.type === 'space') continue;
    l.block(t, 0, WIDTH, s.size, s.align);
    l.y += gap;
  }
  return l.ops.length ? raster(l.ops, Math.max(1, l.y - gap)) : null;
}

// Canvas -> 1-bit data. Threshold 128, or Floyd-Steinberg dither.
function toBits(canvas, dither) {
  const {width: w, height: h} = canvas;
  const d = canvas.getContext('2d').getImageData(0, 0, w, h).data;
  const g = new Float32Array(w * h);
  for (let i = 0; i < w * h; i++) g[i] = 0.299 * d[i * 4] + 0.587 * d[i * 4 + 1] + 0.114 * d[i * 4 + 2];
  const out = new Uint8Array(w * h);
  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      const i = y * w + x;
      const v = g[i] < 128 ? 0 : 255;
      out[i] = v ? 0 : 1;
      if (!dither) continue;
      const e = g[i] - v;
      if (x + 1 < w) g[i + 1] += (e * 7) / 16;
      if (y + 1 < h) {
        if (x) g[i + w - 1] += (e * 3) / 16;
        g[i + w] += (e * 5) / 16;
        if (x + 1 < w) g[i + w + 1] += e / 16;
      }
    }
  }
  return out;
}

export async function renderPage(sections) {
  const parts = [];
  for (const s of sections) {
    const c = await renderSection(s);
    if (c) parts.push({h: c.height, bits: toBits(c, s.type === 'image' && s.mode === 'dither')});
  }
  const height = parts.reduce((h, p) => h + p.h, 0) + GAP * Math.max(0, parts.length - 1);
  const data = new Uint8Array(WIDTH * height);
  let y = 0;
  for (const p of parts) {
    data.set(p.bits, y * WIDTH);
    y += p.h + GAP;
  }
  return {width: WIDTH, height, data};
}

export function drawBitmap(bitmap, canvas) {
  canvas.width = WIDTH;
  canvas.height = Math.max(1, bitmap.height);
  const x = canvas.getContext('2d');
  const img = x.createImageData(WIDTH, canvas.height);
  img.data.fill(255);
  bitmap.data.forEach((b, i) => { if (b) img.data.set([0, 0, 0], i * 4); });
  x.putImageData(img, 0, 0);
}
```

```markdown
# catprinter / web

Web app to print text and images on the MX10 printer from the browser. Public page: https://faijdherbe.github.io/catprinter/

## Browsers

- Chrome or Edge on desktop, Chrome on Android. These have Web Bluetooth.
- Firefox, Zen, Safari and all browsers on iOS have no Web Bluetooth. They show the UI, but they cannot print.
- On Linux, Chrome can need the flag `chrome://flags/#enable-experimental-web-platform-features`.

## Run locally

Chrome does not load ES modules from a `file://` URL. Use a local server:

    python3 -m http.server 8000 -d web

Then open http://localhost:8000/.

## Use

1. Edit: add text sections (GFM Markdown) and image sections. Drag a section on its handle to move it.
2. `->text<-` on its own line centers that line.
3. Preview: the exact 1-bit bitmap that the printer gets. Tap Print.
4. Templates: a template has a TOP and a BOTTOM. Select it on the Edit screen. The app puts your content between them.
5. Printer: darkness, speed and feed. The settings stay in the browser.

The app saves each change at once in the browser (localStorage). To move templates to another device, use Export and Import.

## Install

In Chrome, use "Install app" (desktop) or "Add to home screen" (Android). The app also starts with no network connection.

## Test

    sh web/run-tests.sh

This test is offline and needs no printer. It uses headless Chrome. It prints `ok`, or `FAIL` and the failed checks.
```
